# S4 canonical Team Role acceptance

This directory is generated by `team-role-canonical-visual.spec.ts` against the
repository-built `bin/agent-center` production web chain. The suite signs up a
real organization, creates RAM Roles and a Team through server APIs, then enters
the UI through Teams → Team → Roles → Team Role. Network interception is limited
to deterministic loading, 503, read-only permission, and 409 conflict states.

Coverage:

- right-side editor with Add, Remove, affected members/projects, and Save changes
- successful CAS save followed by authoritative server readback
- 409 conflict with the editor preserved and Refresh latest recovery
- loading, empty, service error, and read-only permission-gate states
- deletion impact/protection confirmation

Reproduce from the repository root:

```sh
make build-backend
cd tests/e2e/v2
pnpm test -- --project=chromium-mac tests/team-role-canonical-visual.spec.ts
```

The screenshot dimensions and SHA-256 digests are intentionally verified in
the delivery report so regenerated evidence can be compared byte-for-byte.
