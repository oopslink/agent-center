# I166 generation 语义与可读性修复计划

1. 历史状态：failed/discarded 优先于 dispatch_records 与依赖推导，撤销明确显示而非 DONE；running/completed/open 分支回归。
2. 稳定代际颜色：时间轴、R 标签、卡片色条共用按 revision 确定的配色；所选代新增强调、前代保留浅底实线、历史撤销虚线。文字保持完整对比度；状态颜色仅在状态标签。
3. 明确快照视角：历史 generation 显示创建时刻，当前 generation 显示实时状态；ACTIVE 改为当前版本；历史孤立撤销节点明确标签。已结束计划的旧控制诊断收起并标明非当前执行结果。
4. 缩放：全图概览、100%可读缩放/定位所选代按钮，时间轴更紧凑且摘要可查看完整文本。保留 agent 点击与背景平移。
5. 单元/组件回归、全量前端测试、lint、build；浏览器以多代隔离fixture检查浅/深色、快照切换、缩放与状态。不访问真实center旁路，不重开旧计划。
