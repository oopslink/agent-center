范围：前端卡片、ELK 展示布局、历史节点标记与画布导航。不修改依赖、任务状态或部署流程。

1. 两行中英文标题、长负责人名：标题最多两行，负责人完整保留；浏览器检查元素边界。
2. 图中孤立 START/END：仅补展示用虚线，明确与调度依赖区分；终点位于流程下方。已存在的边不重复，循环边不参与根叶判定。
3. follows_task_id：仅添加明确的承接展示线，不推断业务依赖；默认显示当前有效节点，历史可切换查看并标记。
4. 完成节点维持文字对比度；压缩层间距，小地图默认收起，可切换；适配全图可用。
5. 回归：ELK 布局单测、PlanDetail 渲染/交互测试、全量 pnpm test、make lint、make build；真实浏览器组件演示含浅/深色与历史切换。浏览器 fixture 仅验证前端，不代表生产上线。
