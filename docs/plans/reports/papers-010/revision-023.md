# 五篇工作稿合并为两篇（023）

**P1–P5 五篇工作稿自本轮起为历史快照，不再是当前成果。** 它们被合并为按**证据类型**切分的两篇：

| 现稿 | 定位 | 取材 |
|---|---|---|
| [A 篇：交付状态的绑定断裂——一个多智能体软件开发部署的现场研究](paper-a-field-study/paper.md) | 单部署回顾性案例研究，结论停在描述与机制解释 | 仅部署记录（消息、任务动作、generation 快照、Git 对象核验、治理事件、读取回执） |
| [B 篇：交接的代价与凭据的可查性——多智能体软件交付的受控实验](paper-b-controlled/paper.md) | 受控实验，真实运行器、真实产物、真实子进程 | 仅新采集的 84 次执行数据，不引用任何部署记录 |

## 为什么合并

五篇共用同一批证据：230 条读取回执同时支撑 P3 与 P5；I05 案例同时进 P1 与 P2；26 个 Plan 的结构统计在 P2 §4.6 与 P4 §4.5 作为两个独立发现出现；P1 §4.8 与 P2 §4.8 共用同一个运行器、同三个任务家族、同一批 54 个条件，两篇的方法段落有整段逐字重复。每篇末尾都声明"跨篇引用不构成独立重复验证"，但单篇阅读时看不到这句的含义——五篇各自看起来都像独立证据。这构成 salami slicing。

现在这一点是**机械可验证**的：`consolidation/checks/crossrefs.py --disjoint` 按原生记录 ID 求两篇证据集的交集，当前为空。合并前同一检查在 P1 与 P2 之间找到 5 条共用 ID。

## 另外改掉的四类问题

**主张强度超出证据等级。** 五篇的标题、摘要与结论写成了效应比较（"costs and quality benefits"、"系统交回未显示优于一次提醒"、"不应有个人名字"），而各自的"证据边界"一节又逐条撤回这些比较的成立条件。现在两篇的主张强度与证据等级逐句对齐，并由 `claim_strength.py` 把摘要与结论中的效应比较措辞作为 blocker 拦住；故意的否定式表述用行内 `<!--allow-banned-->` 标记，使例外显式可审。

**受控实验普遍撞天花板。** 原六组实验近 1,200 次调用几乎只产出零差异，原因写在各篇方法里：输入预先声明了待验证的原则（P1 512/512 已声明 controller 负责修复，P2 256/256 已要求不得把已授权准备工作交给人，P4 256/256 已规定成果丢失时恢复基线）。这些实验现已降为 B 篇附录的"前批次及其天花板诊断"，并重做了实验：提示不预告原则，任务有真实失败空间，终点改为协调成本。

**AI 署名与规范项。** 五篇将 OpenAI Codex 署为共同作者，与 arXiv 2023-01-31 政策冲突（生成式 AI 不得列为作者，只能披露使用）。两篇改为 oopslink 单一作者 + AI 使用声明。伦理改为自我声明、不声称获批或豁免；数据可用性指向只含派生物的脱敏复现包。

**参考文献过薄。** 五篇去重后仅 30 条。现为 A 篇 59 条、B 篇 34 条，新增 38 条全部独立复核（24 条比对 arXiv API 标题、14 条比对 Crossref 标题与年份）；三条查不到可核验出版记录的经典文献舍弃而非编造。

## 数字可复算

`consolidation/repro/package/` 下两个 `verify.py` 从脱敏数据重算论文引用的数字并逐条断言：A 篇 34/34、B 篇 45/45（B 篇的 verify 先校验评分映射哈希与冻结记录一致）。任一条不符即退出码 1。

## 本轮没有做到的

- **英文版与投稿均未处理。** arXiv 自 2026-02-11 起要求非英语投稿附完整英文版（英文在前，允许机器翻译），自 2026-01-21 起对所有分区收紧 endorsement。两项都是后续阶段的必需项，本轮结束时**不投稿，也不声称可投稿**。
- **人工复核仍不完整。** A 篇 §4.1、§4.2、§4.6 的分类有作者对 25 条随机子集的人工判定（一致率待填）；§4.3–4.5 的分类只有 AI 编码。B 篇全部分析未经独立人工复核。
- **终检的判断层由派发的评审而非人类完成**，见 `consolidation/audit/README.md`。
