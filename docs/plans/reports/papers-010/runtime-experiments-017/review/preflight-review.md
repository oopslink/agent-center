## 3 可解释范围与尚缺项

P1现在回答固定split拓扑、明确能力和同一失败交接下，身份归属呈现与持续状态供给是否改变自主恢复。它不回答架构净效应、训练来源或自然executor失败发生率。研究者种下的初次失败、后续自然模型失败和成功修复必须分开；一次短函数交付也不能证明长时段责任稳定。

P2比较同一四类必需工件下，合并／分离角色与关系表示的具体组织方案。会话、权限分区、交接成本共同变化；长链完成基础职责后恢复预算较少，这是固定资源下的组织成本，不等同认知混淆。最终产物和隐藏验收为主要结果，消息解释另作探索性编码。

每篇仅三个任务族、两个请求模型、每条件一次。可报告全部运行的配对描述与反例，不能把调用/轮次当独立样本，不能从零差异证明普遍等价，也不估稳定发生率。任务与oracle来自本研究AI，独立进程执行并不等于独立人工内容效度验证。CLI按完整历史重建上下文，也不是历史Agent Center生产重放。

不得将不改文件动作数、预算耗尽、公开检查通过或request_external直接改写为停摆、责任混淆、独立验收通过或合法/非法升级。所有这些边界已进入协议，不以未来结果是否符合预期决定保留与否。
