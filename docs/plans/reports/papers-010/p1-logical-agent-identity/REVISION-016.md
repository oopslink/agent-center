# P1 revision-016：问题与证据效度修订

作者：oopslink；无资助。五稿仍为探索性工作稿，尚未人工复核。

题名由“Supervisor–Executor 架构中的身份抽象与责任归属”收窄为“Supervisor–Executor 架构中的责任连续性失效：Agent Center 案例研究”。正文以具体可观察问题组织；文献改为机制与评价对象比较；事后分析框架明确构念、判据、反例及正文应用位置。它不是已验证的普遍理论或预注册分析。

**影响结论的审计发现。** 对全部512个主动作输入的事后核查表明，512/512已经声明controller承担后续修复或合法升级，64/64个修复情境还提供精确且获授权的修复。实验因此固定了真实部署中最需解释的责任义务，只操纵其余表示条件。它能检验显式协议的遵循与干扰，不能独立验证责任会自主维持。

**实际修订。** 摘要/研究问题、相关研究、分析框架、构念检查和结论中的证据承诺相应调整；图表、原始数值与反证保留。新增或更新引用按首次出现重排IEEE编号，Bib键维持身份；编号映射在共同审计包。P1保留多次人工纠偏与后期残留，P5的三层实现说明不冒充三层效果比较。

**尚未完成。** 最小判别研究需固定合法恢复入口、任务事实与模型配置，让同一组未见任务经历多轮可修复的executor失败；分别操纵身份封装和恢复义务的表达／维护方式，预先安排身份提醒与具体行动提醒。主要结果是无提醒承接修复、合法升级和最终验收，辅以人工介入次数。若统一身份在此条件下不增加责任外置，当前案例便不足以支持身份封装的独立效应。
