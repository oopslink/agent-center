## 3 材料与方法

### 3.1 历史案例与源码

本研究对同一部署的冻结记录开展目的性案例分析，结合历史身份契约、设计初稿和监督检查案例，分别考察设计意图、责任解释与后续动作。定向检索与阅读的范围见表1，精确记录、检索过程和复算入口见[补充附录](evidence-details.md)。设计文档用于重建方案由来，不能替代历史部署状态。（A00、A01、A14）

过程重建依次记录技术或交付失败、责任解释、可用权限与动作、人工提醒及后续响应。消息用于识别参与者的判断，Task动作与领域审计用于确认状态转换，固定源码用于核对提示和控制协议的变化。执行体创建若只有Agent报告，始终保留为报告级证据。8月主案例未恢复原生fork事件；9月补查则能把用户指令与新Task创建、启动关联，但仍不等于最终交付。（A04、A05、A21）

纳入片段须能定位具体行动或交付责任。线程、工作区、配置及恢复接口故障不承担架构后果归因；其中可独立辨认的责任外推仍按表述与行为证据分别保留。若当前主体缺少合法恢复能力，合理升级和等待不算身份错误。本文同时纳入明确承责而拒绝不合格产物、以及监督检查增加具体要求的反例。后期正例并非未经人工干预的基线，不能用来撤销早期纠偏事实。全部分析尚未人工复核，没有重跑历史模型或实施实际架构消融。（A02、A03、A10–A12、A21）

操作者本轮补充了“早期经常混淆、多次提醒后逐步改善、后来仍偶发”的回顾性观察，作为A20单独保存；7月23日的当时诊断与此回顾分开。新增只读检索从26,961条消息中得到8,866条角色词候选，其中149条为用户消息，32条再命中责任相关词；这些是发现材料的范围，不是错误或干预次数。随后定向整理9组材料、34个消息锚点、9个会话容器及3个Task的6条动作，并非逐条标注全部149条候选；详见[纵向取证附录](longitudinal-analysis.md)。缺少连续暴露分母、精确部署及完整输入，不能把操作者体验换算为发生率、学习曲线或同一模型的永久改善。（A20、A21）

本轮机制补查另检查三次历史提交及其父版本的身份提示、派发控制与工具说明，并核对两篇训练研究。采用竞争解释比较：对每项机制分别记录支持、反证、替代解释和可区分干预。源码仅证明指定版本的实现，消息仅证明可见表述；二者不能自动拼成当次模型输入。新增来源与筛选处置见[机制研究附录](mechanism-analysis.md)。（A15–A17）

### 3.2 受控动作实验

为先排除可控的接口和上下文混杂，另构造八类状态情境，覆盖尚未启动、恢复后无执行体、已有待受理请求、健康执行、健康未知、执行会话无中心权限、拒绝后修复和外部审批缺失。工具描述与确定性状态转换逐项核对；模型输出一个JSON动作，外部模拟器判断其主体、权限与状态效果。正确等待和合法上报均可达到对应控制边界，多余检查则单列为合法未推进，不自动编码成身份混淆。这些是从案例机制提炼的合成短题，不是历史生产事故重放。（A18）

实验交叉四个二水平因素：工具说明一致／保留reset自动派发旧措辞，无旧协议／带明确标为旧版的自动派发记录，一个逻辑Agent内部两种角色／两个共享任务归属的运行组件，以及Supervisor–Executor／Control unit–Work unit标签。两身份组的归属、权限、当前行动者、上下文边界与交付责任完全相同，只改变一句身份表述。对冻结输入逐条核验，512/512个正式动作prompt都明确规定controller负责最终裁决以及后续修复或合法升级；64/64个S7输入还直接给出精确且已授权的修复、无活动执行体、继续交付目标及专用queue_repair动作。因此，该对照测量的是充分说明下的表述效应，没有改变进程拓扑，也没有测量模型能否在失败后自行维持责任、寻找恢复路径。干净子集仅指说明一致且无旧规则，其余用于指定干扰诊断；“干净”不表示已排除历史运行的全部混杂。（A22）

固定模型为`claude-sonnet-5-5`与`claude-haiku-5-5`，经同一Claude CLI 2.1.317调用，effort均为low。每次以新进程、空工作目录、无真实工具、无项目定制与会话持久化运行；归档历史只按因素有意加入。CLI与服务可能仍有不可见固定提示，隔离条件不等于纯模型权重。16条件×8情境×2呈现版本×2模型共512次动作选择；两呈现版本调整工具顺序、归档位置和对象ID，是固定稳健性检查，不是独立随机重复。另以32次规则不完备的诊断观察默认主体选择，允许回答“未指定”，不计算正确率。

输入、规则和调用脚本在正式任务输出前以哈希冻结；2次连通性请求不计入分析。内容错误不重试，传输失败最多重试一次。预定的16组恢复观察复用首步，只有未推进时才追加至多两步模拟器反馈。所有有效内容与失败记录均保留，身份和标签效应在干净子集内按情境及呈现版本配对，分别报告模型结果。固定情境的交叉组合不作为独立生产任务，不作总体发生率或训练来源推断。完整协议、原始返回和评分依据见[实验附录](controlled-experiments.md)。（A18、A19）
