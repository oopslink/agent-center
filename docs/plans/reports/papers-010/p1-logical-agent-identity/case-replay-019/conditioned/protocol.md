# 补充问题：从历史等待路径恢复

第一组实施中已读过部分结果，可修首答倾向继续分派。因此在补充组调用模型前另行冻结方案，作为事后增加的探索，不覆盖首组、不追加到自发复现分母。目的只在检验给定此前已登记等待的多轮历史，能否在发现资源现已可用后恢复。每个家族×模型两个采样重复；同一格的历史是相同材料，不是两个独立历史案例。共8个匹配块、24个分支。源于 L01/L02 的“等平台恢复或替代任务”“等提供仓库”的去标识转述，只把可核对的等待决定置于历史；不提供用户原话、模型事后承认或错误身份诊断。各支均得到同一份新的可分派资源回执；当前技术障碍已消除。该资源更新本身可能促进恢复；没有在障碍持续时强迫重试。N/H/R干预、最多四决策、第一次新候选业务错误、真实验收及格式规则不变。无正式的人类参与，不做跨组因果比较。结果：首次实际重新分派（或先查询后分派）、终态验收、错误等待／合理升级和严格外置；若无明确外置语言，不把给定等待史等同于已给定身份错位。保留各条件全部结果、费用、错误、候选和原始调用。
