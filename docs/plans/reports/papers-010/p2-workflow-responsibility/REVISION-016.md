# P2 revision-016：问题与证据效度修订

作者：oopslink；无资助。五稿仍为探索性工作稿，尚未人工复核。

题名由“多智能体工作流中的协调失效与责任分配”收窄为“多智能体软件工作流中的行动绑定与协调失效”。正文以具体可观察问题组织；文献改为机制与评价对象比较；事后分析框架明确构念、判据、反例及正文应用位置。它不是已验证的普遍理论或预注册分析。

**影响结论的审计发现。** 全部256个主输入直接要求不要把已授权的准备工作交给人，并说明gate是谓词而非必经工具调用。因而本实验不是对真实工作流长度或人工依赖的操纵，不能据语义全对证明已解决协调停摆。W2/W8的有效性问题涉及2/8情境，其全部64个条件输出按原记录保留；材料修复后的结果缺独立新情境检验，不能回写成无缺陷的确认性实验。

**实际修订。** 摘要/研究问题、相关研究、分析框架、构念检查和结论中的证据承诺相应调整；图表、原始数值与反证保留。新增或更新引用按首次出现重排IEEE编号，Bib键维持身份；编号映射在共同审计包。P1保留多次人工纠偏与后期残留，P5的三层实现说明不冒充三层效果比较。

**尚未完成。** 最小判别研究应增加真实异步交接和依赖步骤，而非仅把一个谓词拆成八个标签；在相同目标、信息、权限和质量门槛下，比较隐式交接与明确行动绑定。预先固定未见任务、恢复机会和停止标准，测无人工提示的推进与验收。若绑定关系后仍同样停摆，应转查执行能力、运行机制或任务本身，而非继续归责于职责措辞。
