# A 篇的删除与降级决定

本文件记录从五篇初稿**不进入** A 篇的内容，以及理由。删除不是为了压篇幅，而是因为这些内容的结论站不住或与 A 篇的证据等级不符。

## 1 整段删除

### 1.1 P3 §4.5、§4.7：角色读取重合度分析

删除。该分析给出同角色与跨角色 Jaccard 平均差的四种口径：

| 口径 | 差值 |
|---|---|
| 同 commit，所有配对等权 | 0.074 |
| 同 commit，共同分层等权 | 0.063 |
| 同 commit 及 phase，配对等权 | 0.142 |
| 同 commit 及 phase，共同分层等权 | 0.033 |

P3 原表 6 进一步显示，限定 phase 后逐一删层的范围是 **−0.0443 至 0.0798**，跨过 0。也就是说结论的符号由汇总口径决定。保留它等于保留一个自我抵消的分析，并会给读者一个"同角色共享更充分"的暗示，而这个暗示在作者自己的敏感性分析里就不成立。

**替代处置：** §4.3 只保留"共同事实已跨命名成员与角色边界到达"这一可核验的描述（230 条回执、12 个 Agent、34 条版本化规则中 30 条被至少两个 Agent 读取），不报任何同角色／跨角色差值。原分析与底表留在旧稿与 `research-validity-016/`，供需要的读者追溯。

### 1.2 P3 §4.9：三种命名条件的 48 次处置

降级，移入 B 篇附录。六个条件全部 8/8，既无方差也未做等效性检验（P3 §6.2 自认）。它不能支撑"不应设个人名字"这一规范结论，但作为"该设计在短任务上未检出差异"的零结果记录有保留价值。

**替代处置：** A 篇 §4.3 只陈述机制层的事实（稳定 ID 承担机器引用、角色描述职责、授权决定可达范围，三者可分别实现），不引用这 48 次处置；B 篇附录以零结果形式报告，并明确说明无等效性检验。

### 1.3 P1 §4.6–4.7、P2 §4.7、P4 §4.7：短题动作选择实验

不进 A 篇。三篇的输入都预先声明了待验证的原则（P1 512/512 已声明 controller 负责修复，P2 256/256 已要求不得把已授权准备工作交给人，P4 256/256 已规定成果丢失时恢复基线），因此测到的是"协议已明示后的遵循"，与 A 篇"现场记录的描述与机制"不是同一证据类型。

**替代处置：** 全部进 B 篇附录"前批次及其天花板诊断"。

## 2 合并

### 2.1 P2 §4.6 与 P4 §4.5 的结构统计

两篇把同一组数字当作各自的发现呈现：26 个 Plan 的累计节点数中位数由 8 增至 17.5、seq 最长路径 3→6 条边、最大拓扑层 3→6.5 个节点、不同 assignee 中位数两端均为 6.5。

**处置：** 在 §4.4 一次性呈现，§4.6 只在需要时引用，不重复作为独立结果。

### 2.2 边 Jaccard、父节点保留率、留一敏感性

从正文移入附录。169 次转移的边 Jaccard 中位数 0.680［0.500–0.833］、新增边元组中位数 3［2–5］、删除 1［0–3］、留一保留率区间 85.4%–91.1%。这些量描述"记录里改变了什么"，不支撑任何一类绑定断裂的论点；P4 §4.6 结尾自己也这么说。正文只保留与论点直接相连的三个数：169 次转移、149 次保留全部父节点、166 次拓扑改变中 101 次有共有任务转为完成（不变的 3 次中 1 次）。

## 3 不修的已知假阳性

### 3.1 P1 的 §11 悬空指向

`crossrefs.py --paper` 对 P1 报 `dangling_sections: ["11"]`。来源是证据表 A14 的"§1–8、§11–12"，指向被引设计文献的章节，不是本稿小节。

**处置：** 不改检查器。A 篇改用"该文献 §11–12"的写法，使指向不再被误读为本稿小节。
