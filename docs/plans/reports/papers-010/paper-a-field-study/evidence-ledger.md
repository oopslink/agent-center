# A 篇证据台账

每一行登记：这段内容属于哪一类绑定断裂、取自初稿的哪个片段、对应的原生 ID、证据级别、进 A 篇的哪个小节。
**证据级别**决定正文能说到什么程度：

| 级别 | 含义 | 正文允许的表述 |
|---|---|---|
| 原生记录 | 冻结数据库中的消息、任务动作、generation 快照、读取回执、治理事件 | "记录显示……" |
| 产物核验 | 本研究实际执行过的只读 Git 对象检查（祖先、文件存在、完整树） | "核验确认……" |
| 参与者报告 | Agent 或用户在消息里的自述，未被独立复核 | "……报告称" |
| 源码静态阅读 | 指定 commit 的提示、工具说明或入口实现 | "该版本源码中……" |
| AI 分析 | 本研究的编码、分类与解释 | "本文判定……"，并受 §3 的人工子集一致率约束 |

`§4` 各小节是六类断裂；`§1`–`§3`、`§5`–`§7` 的小节也登记来源类型，使每个叶子小节都有声明的出处。
