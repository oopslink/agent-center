## 三项需要改变结论层次的发现

1. **实验操纵窄于研究问题。** P1的512个输入已规定修复责任；P2–P4各256个输入也明示相应行动、名称或图语义规则。正确响应能说明给定协议下的行为，不能验证这些原则在长期执行中的自主形成与维持。
2. **P3没有测“无名字”。** 两套标签均保留显示身份；角色/个人过滤的覆盖差由选择器构造，bounded不是实际检索器。保留该反例，但撤回命名必要性或最优共享策略的效果推断。
3. **P5的主要证据是约束冲突。** 57次Git/事件对应及230次读取支持通路；宽规则和条件化规则发生在不同任务。它们提供机制对读，不提供三层记忆或规则条件化的净收益。

P1的生产失败没有被短题结果否定：早期责任外置、反复人工纠偏、后续正确承责与再次出错继续作为主要发现。操作者所述的频度变化仍单列为回顾材料，不编造成发生率趋势。
