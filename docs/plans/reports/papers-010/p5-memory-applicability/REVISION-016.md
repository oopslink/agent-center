# P5 revision-016：问题与证据效度修订

作者：oopslink；无资助。五稿仍为探索性工作稿，尚未人工复核。

题名由“多智能体系统中的分层记忆管理与知识适用性”收窄为“多智能体共享记忆中的规则适用性：团队规范与任务合同的冲突”。正文以具体可观察问题组织；文献改为机制与评价对象比较；事后分析框架明确构念、判据、反例及正文应用位置。它不是已验证的普遍理论或预注册分析。

**影响结论的审计发现。** 本稿没有记忆机制对照实验。M02与M03分别位于不同任务且伴随人工提示、证据和图变化，属于机制对读，不能计算条件化规则的干预效果。私有历史缺失使“agent／项目／Team哪层更有效”目前无法回答；读取回执也没有提供全部复用机会的分母。

**实际修订。** 摘要/研究问题、相关研究、分析框架、构念检查和结论中的证据承诺相应调整；图表、原始数值与反证保留。新增或更新引用按首次出现重排IEEE编号，Bib键维持身份；编号映射在共同审计包。P1保留多次人工纠偏与后期残留，P5的三层实现说明不冒充三层效果比较。

**尚未完成。** 最小判别研究先在相同候选和合同上回放无条件规则、条件化规则、旧新并存与显式替代四种版本，验证约束是否一致；再用未见任务和跨会话执行比较实际采用。私人保存、pending与canonical发布的可达性另作固定权限比较。主要结果为合同相容的采用和独立验收，访问量只作中间指标；所有比较均尚待执行。
