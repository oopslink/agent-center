# P5 修订 020

《多智能体团队中的组织记忆：分层存储、跨成员传播与规则适用性》。题名、中英文摘要、理论框架、方法、研究发现 与结论已对应修订。团队经验从私有、项目作用域传播至 Team 后，什么时候能被正确复用？ 项目目录仍属私有仓库，Team 发布支持跨成员读取。宽规则在 4 次中间交接中阻断 1 次，另 3 次仍推进；无规则、条件化和显式替代均 4/4 推进。最终门禁四组均守住。
