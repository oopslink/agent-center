# P3 revision-016：问题与证据效度修订

作者：oopslink；无资助。五稿仍为探索性工作稿，尚未人工复核。

题名由“多智能体系统中的命名、角色与上下文共享”收窄为“多智能体协作中的显示身份与信息边界”。正文以具体可观察问题组织；文献改为机制与评价对象比较；事后分析框架明确构念、判据、反例及正文应用位置。它不是已验证的普遍理论或预注册分析。

**影响结论的审计发现。** 全部256个主输入明确声明显示名不改变稳定ID或权限，并给出当前候选的处置规则。Nora/Luca与Q104/Q207两条件均有显示标签，没有无显示名对照。personal、role、all与bounded的充分性3/8、2/8、8/8、8/8由固定材料选择器决定；bounded按目标字段筛选，不是实现并验证过的检索器，也没有使用角色分类。因此其优势是受控信息供给下的可判定性，不能外推为实际检索或角色共享收益。

**实际修订。** 摘要/研究问题、相关研究、分析框架、构念检查和结论中的证据承诺相应调整；图表、原始数值与反证保留。新增或更新引用按首次出现重排IEEE编号，Bib键维持身份；编号映射在共同审计包。P1保留多次人工纠偏与后期残留，P5的三层实现说明不冒充三层效果比较。

**尚未完成。** 命名研究需比较无显示名、人名和角色标签，同时保留稳定机器ID与权限，并跨多个词汇集合和未见任务重复；上下文研究需另外实现检索器，在同预算和事实真值下比较角色视图、任务视图与二者结合。直接处置、缺信息请求和越权分开评分。团队感需另有自愿参与者与经过检验的体验量表，现有一人自述不能承担该估计。
