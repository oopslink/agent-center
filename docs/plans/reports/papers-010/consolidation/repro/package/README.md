# 复现包（只含派生物）

本包用于复算两篇论文正文引用的数字，并复核产物级检查。**原始协作对话不在其中。**
因此论文中的案例可以按标识追溯到授权的本地档案，但不能从本包还原到具体个人。

## 脱敏规则

由 `sanitize.py` 施加，逐条可核：

| 规则 | 替换为 |
|---|---|
| 本机 home 绝对路径（`<ARCHIVE>`、`<ARCHIVE>`） | `<ARCHIVE>` |
| 独立出现的作者用户名 | `<AUTHOR>` |
| 内部主机名（`*.local`） | `<HOST>` |
| 二进制文件 | 不复制，在 `MANIFEST.json` 的 `skipped_binary` 中登记 |

`MANIFEST.json` 给出每个文件的 SHA-256 与字节数。可用 `sanitize.py --check` 复验本包无残留泄漏。

## A 篇｜现场研究

```
cd a-field-study && python3 verify.py
```

从本目录的数据重算 A 篇正文引用的 **34 个数字**并逐条断言，包括：

- `task-graph/` —— 169 次父子转移的拓扑与状态变化、逐 Plan 留一的父节点保留率区间
- `rule-audit/` —— 230 条去重读取回执（12 个 Agent、2 个团队、8 个提交）、按 `(团队, 提交, 规则)` 计的 34 条版本化规则、治理事件与提案状态
- `git-verification/` —— 十项只读 Git 对象核验的命令、退出码与结论
- `recompute/` —— 论文正文的数字复算脚本（`recompute.py`）与既有聚合（`reanalysis.json`）

`verify.py` 失败即说明论文正文与数据不符，应以数据为准。

**不包含：** 冻结消息库、任务动作日志原件、generation 快照原件、私有记忆仓库。这些含协作对话与内部路径，保存在授权的本地档案。

## B 篇｜受控实验

```
cd b-controlled && python3 ../../runner/analyse023.py --episodes episodes --lock design-lock.json --out analysis.json
```

B 篇的实验数据**没有隐私问题**，因此完整公开：冻结设计与 design-lock（含评分映射哈希）、每个 episode 的全部模型请求与响应、工具事件、产物版本、回执对象，以及评分脚本本身。分析脚本启动时自校验评分哈希，不一致即退出，以防评分映射事后漂移。

## 本包不能证明什么

- 不能证明历史部署的完整输入：当次部署版本、完整模型输入与执行控制轨迹均未保留。
- 不能替代产品行为验收：Git 核验只覆盖指定对象的祖先、文件存在性与完整树关系。
- 不能提供案例判定的人工复核：分类的一部分有作者对随机子集的人工判定，其余只有 AI 编码，见 A 篇 §6.3。
