# P4 revision-016：问题与证据效度修订

作者：oopslink；无资助。五稿仍为探索性工作稿，尚未人工复核。

题名由“智能体任务图演化中的产物继承与验收语义”收窄为“智能体任务图演化的交付语义：产物继承与验收范围”。正文以具体可观察问题组织；文献改为机制与评价对象比较；事后分析框架明确构念、判据、反例及正文应用位置。它不是已验证的普遍理论或预注册分析。

**影响结论的审计发现。** 全部256个主输入直接规定图历史、产物和验收范围分离，指定必要成果丢失时恢复基线，并声明关闭历史没有当前执行依赖。原实验据此测规则已明示后的选择，未检验这些原则能否被自主发现，也未操纵真实静态／动态图策略。D5/D8的动作分类重叠涉及2/8情境，全部64个输出保留为材料问题；修复后结果属于事后诊断而非独立确认。

**实际修订。** 摘要/研究问题、相关研究、分析框架、构念检查和结论中的证据承诺相应调整；图表、原始数值与反证保留。新增或更新引用按首次出现重排IEEE编号，Bib键维持身份；编号映射在共同审计包。P1保留多次人工纠偏与后期残留，P5的三层实现说明不冒充三层效果比较。

**尚未完成。** 最小判别研究应在相同初始产物、合同与外部条件下比较原任务续修、局部改图和重新规划，实际执行代码修改及独立验收；图策略不能同时改变可用证据和责任协议。任务家族及重复运行应预先确定，记录成果丢失、重复劳动、质量与成本。若局部改图没有组织额外义务却增加工作，其净效用才有可比较的负面证据。
